# AtlasLoot-CoA v8.1.6 — Full Phase 1 & 2 BiS Database

- Integrates the generated Best in Slot dataset for 21 CoA classes and 70 specializations.
- Includes 140 Phase 1 and Phase 2 class/spec lists and 13,404 ranked item entries.
- Includes both required folders: AtlasLoot and AtlasLoot_Cache.
- Extract both folders into Interface/AddOns.

The imported rankings and class equipment restrictions have not all been independently verified, and the package still needs in-game testing. This release is marked as a prerelease.
